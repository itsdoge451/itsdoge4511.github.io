# 🎥 9MB Media Compressor

A beautiful, fast, and easy-to-use web application to compress video and audio files to your desired file size.

## ✨ Features

- **📁 Easy File Selection** - Click "Browse Files" to select any video or audio file
- **⚡ Instant Compression** - Compress files to your target size (1-500MB)
- **🎯 Quick Presets** - One-click compression to common sizes (5MB, 9MB, 20MB, 50MB)
- **🎨 Quality Control** - Choose between Low, Medium, or High quality levels
- **📊 Real-time Feedback** - See original size, compressed size, and reduction percentage
- **📥 Easy Download** - Download your compressed file with one click
- **📱 Responsive Design** - Works perfectly on desktop, tablet, and mobile devices

## 🚀 How to Use

1. **Click "📁 Browse Files"** to select a video or audio file from your computer
2. **Set Target Size** using the slider on the right panel (default: 9MB)
3. **Choose Quality Level** - select between Low, Medium, or High
4. **Click "⚡ Compress"** and wait for the compression to complete
5. **Click "📥 Download"** to save your compressed file

## 🎬 Supported Formats

**Video Formats:**
- MP4, WebM, Ogg, MOV, AVI, FLV, MKV, and more

**Audio Formats:**
- MP3, WAV, AAC, OGG, FLAC, M4A, and more

## ⚙️ Compression Settings

### Quick Presets
- **5 MB** - Ultra-compact (highest compression)
- **9 MB** - Balanced (recommended)
- **20 MB** - Good quality
- **50 MB** - High quality

### Quality Levels
- **Low** - Smaller file size, faster compression
- **Medium** - Balanced file size and quality
- **High** - Larger file size, best quality preservation

## 🔧 How It Works

The app simulates media compression using intelligent algorithms that:

1. Calculate the compression ratio based on your target size
2. Adjust compression based on quality settings
3. Process your file and provide real-time progress
4. Generate a compressed version for download

## ⚠️ Note

This is a client-side compression simulator. For production use with real video/audio encoding, integrate with FFmpeg or similar backend services.
